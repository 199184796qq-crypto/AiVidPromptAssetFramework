# 框架升级与同步

状态：用户已确认，R003。适用于所有机器及 Agent。框架发布源为 https://github.com/199184796qq-crypto/AiVidPromptAssetFramework 。

## 获取新版

用户要求“升级框架”“更新框架指令”时，读取当前安装路径、版本与远程状态。该请求授权获取已发布版本，不授权自行设计新规则，不需要为单纯获取新版另开 Agent 设定。
先按编辑锁保存未保存的项目进度；无新改动不重复保存。备份当前框架及活动指针，获取目标版本并比较变更、规则清单与硬规则校验。不得把仓库新内容未经核验直接覆盖到正在使用的技能目录。
本地有修改时保留副本；冲突保留双方并报告，不强制覆盖。硬规则有差异、校验失败或目标版本资料缺失时，停止激活并报告，保留原版本；不得解除只读保护或自动升级冻结内容。
验证通过后应用普通规则更新，记录安装版本、来源提交、路径映射和校验结果，重新读取先读我、当前活动规则及适用专项规则，然后继续工作。不把下载成功当作已加载成功。

## 修改并发布

只有用户明确开启 Agent 设定后才可设计和修改普通规则。先保存旧版，登记变更、来源版本及用户确认依据，再验证入口引用、版本记录及冻结文件未变。发布到 GitHub 必须有用户的同步或发布授权。
推送前核对远程是否有其他 Agent 的更新；不得强推覆盖。存在冲突时保留版本并请求用户裁定。推送成功后核验远程提交，报告版本；失败时准确区分本地已保存和远程未同步。

## 项目与交接

升级不自动改写项目剧情、分镜、提示词或历史归档。项目保留原规则快照；采用新版进行创作时记录新工作版本的规则依据。
其他 Agent 只有能访问发布源、完成更新并重新读取后才算使用新版，不能声称所有 Agent 已自动同步。交接记录标明实际加载的版本与尚未处理的兼容事项。
