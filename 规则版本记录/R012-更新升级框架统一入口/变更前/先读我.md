# H3 技能包总说明｜先读我

用户说“本地升级”即明确选择本地优先，直接按 用户定制规则/框架升级与同步.md 读取本地入口与适用规则，不再询问升级方式。

启用辅助技能时必须按 用户定制规则/辅助技能扩展机制.md 展示其自身流程与强制要求、逐项执行、交由用户裁定冲突，再将有效结果融合到上一步版本。

创作入口必须先执行 用户定制规则/故事先审后选模型.md：先展示通用文字故事，用户通过后再选择模型并调用对应主 Skill 生成基础提示词。

每次远端发布必须执行 用户定制规则/首页更新记录规则.md，同步更新根目录 README.md 的说明和倒序更新记录。

辅助技能的安装、选择、引导、归档和跨 Agent 恢复按 用户定制规则/辅助技能扩展机制.md 执行；登记表位于 辅助技能/技能登记表.json。安装不等于本条提示词启用。

用户说“升级”而未指定方式时，先按 用户定制规则/框架升级与同步.md 提供本地优先、远程升级供选择；本地优先只有找不到本地先读我.md 才访问远程。

生成提示词按 用户定制规则/提示词优先交付.md 执行：必要检查后先展示，再做保存、索引及已授权归档。

获取新版框架或修改发布时，读取 用户定制规则/框架升级与同步.md；区分加载已发布规则与自行修改规则，核验后再激活。

任何可能离开当前视频编辑状态的操作，必须先读取并执行 用户定制规则/离开编辑状态强制落盘.md；包括列出历史、回看、切换、开始其他工作、暂停或结束。保存并读回核验成功后才能离开。

所有 Agent 首先读取 用户定制规则/硬规则锁定清单.md。清单及其中列出的官方技能、续写冻结基准只能读取，绝对禁止修改。

按该文件的编辑锁判断是否有新改动：已锁定且无新编辑时不重复落盘；发生新编辑后再保存。

每份 H3 提示词都必须有对应剧情版本；回看、修改和恢复按 用户定制规则/提示词与剧情双版本规则.md 执行。

多智能体或换机器接手时，读取 用户定制规则/多智能体协同规则.md，按统一事实来源和编辑锁交接，不依赖聊天记忆。

同一项目涉及多个生视频工具时，读取 用户定制规则/多引擎提示词归档规则.md，分离共同项目层与各引擎提示词层。

项目内视频与可选分镜按 用户定制规则/视频剧情与分镜记录规则.md 管理；未生成分镜时不虚构记录。

规则恢复、列出新增规则和回退按 用户定制规则/规则版本与回退控制.md 执行，并读取当前活动规则索引。

用户说“Agent设定”时，按 用户定制规则/Agent设定入口.md 进入框架与规则规划状态，不启动视频任务。

只有 Agent 设定明确开启期间才允许修改或回退规则；未开启时规则请求只记录待议。

用户选择续写后，必须先读取 用户定制规则/续写类型分流规则.md，确认物理延续或逻辑延续；只有物理延续启用 Motion Context 与冻结首镜规则。

启动顺序以 用户定制规则/项目地址启动入口.md 为准：先确认项目地址，再确认新视频/续写和预设。本文后续旧有“第一问新视频/续写”顺序由此替代。

归档视频项目时必须读取 用户定制规则/项目归档与复现.md，把预设快照、实际提示词、素材及已知依赖保存到具体项目，核验并列明缺失项。

查看或选择预设、查看或切换视频项目时，读取 用户定制规则/预设与项目列表.md，列出真实记录并支持数字选择；查看本身不改变状态。

用户说“列出历史”时，先执行离开编辑状态强制落盘，再逐项询问范围：1. 当前项目；2. 其他项目。

多视频管理必须读取 用户定制规则/多视频切换规则.md。中途创建其他视频前保存当前状态；返回已有视频恢复其独立记录，不重置设定、不混入其他视频内容。

你正在使用用户定制的 H3 提示词技能包。读完本文件后，按下面的入口自行读取所需文件，无需用户重复粘贴规则。所有路径均相对于本文件所在目录，移动文件夹后仍按相对路径解析。

## 使用原则

- h3-prompt-writing/ 为官方原版，只读使用，不修改、不覆盖、不自动升级。
- 用户定制规则在官方文件之外约束任务。针对中文先审、两块交付等明确要求，按定制协议执行；不因此改写官方文件。
- 包内文档出现原电脑 E:\H3的技能 的路径时，指本文件所在根目录；原测试素材的绝对路径不能视为在当前电脑存在。
- 新任务先确认剧情继续还是新剧情，每次只问一项，尽量用数字选择。用户已明确给出的信息回显确认，不重复索要。
- 固定音频句式逐字执行，仅替换编号；不因模式切换、重新生成或语言润色改变。
- 最终交付为两个独立文本可拷贝块：素材上传顺序、H3 提示词。先中文审核，明确通过后才给英文；禁止代码块。
- 若当前平台原生支持 writing block，使用其渲染方式；不支持时优先采用平台原生的独立可复制文本容器。若无法满足，简短说明平台限制，不把不支持的标记当成已成功显示的文本块，也不改用代码块。
- 用户对本次内容的修改只更新本次状态；只有明确要求修改通用规则时才保存到用户定制规则。仅覆盖直接冲突项，其余保持。

## 继续已有测试与新任务

只有用户明确要求继续本包中已有测试时，才读取 用户定制规则/当前测试状态.md 并恢复状态。
新任务不自动继承其中的剧情、人物、音频模式、时长和画幅。
命名预设机制已启用，必须读取 用户定制规则/命名预设与本次覆盖.md；具体活动预设以预设库记录为准，旧方案仅作历史记录。

## 首次响应

读取上述必要文件后，直接按规则处理用户当前需求，不要求用户重新解释本说明。
若用户只是要求启用本包，简短告知规则已读取，然后问第一项：本次是剧情继续还是新剧情，提供数字选项。
若某必需文件确实无法读取，准确说明缺少的文件，不声称已加载。

## 续写入口补充
用户选择续写视频时必须读取 用户定制规则/续写视频首镜衔接规则.md。起始选项统一为1. 新视频；2. 续写视频。不强制上传上一段视频，以现有信息编写首镜连续动作。

## 续写冻结基准：与官方技能同级保护

续写时必须读取 续写衔接冻结基准-v1/README.md 与 续写衔接冻结基准-v1/已确认续写理解与时间规则.md。
这两份文件及来源校验记录，与官方技能享有相同的不可改写、不可覆盖、不可删除、不可自动更新保护。用户定制规则/续写视频首镜衔接规则.md 也是同内容的只读规则，不得继续追加改写。
这里的同级指用户项目内的保护与执行基准，不能覆盖系统约束，也不把第三方说明称为 MiniMax 官方文件。
后续新增理解或规则只能另存补充或新版本，用户明确确认后才生效，仍保留 v1 原件。遇到两份基准具体冲突先说明，不擅自修改任一原件。
