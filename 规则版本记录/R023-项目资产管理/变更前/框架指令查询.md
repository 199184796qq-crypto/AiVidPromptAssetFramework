# 框架指令查询

状态：R019，用户明确要求添加 ver 与 list。

在本框架对话中，独立指令 ver 等同框架版本，按 框架版本查询.md 执行；list 等同列出框架指令，显示以下指令及解释。忽略大小写和首尾空白，不把代码、路径、引用文档中的单词当作用户指令，不把 ver 或 list 交给操作系统执行。用户明确询问其他工具的同名命令时按其明确对象处理。
查询无需进入设定。list 不执行表内命令，不升级、回退、切换项目或启用技能；如需离开编辑状态按已有保存规则处理。以当前活动规则为准，后续新增、改名或停用指令时同步维护此表；不得将设想功能写成已实现。原本有前置条件的命令仍保留条件。

| 指令或自然语言 | 解释 |
| --- | --- |
| ver / 框架版本 / 查询框架版本 | 查询本地规则版本、变化及可核实的加载与同步状态；默认不联网 |
| list / 列出框架指令 | 显示框架命令和解释，不执行这些命令 |
| 开启设置 / 开启设定 / Agent设定 | 进入框架普通规则规划及配置状态；不启动视频任务 |
| 更新框架 / 升级框架 / 本地升级 | 重新读取本地入口、核验加载；只有找不到本地入口才转远程 |
| 远程更新框架 / 远程升级框架 | 获取并核验远端版本，保留本地改动；不修改冻结文件 |
| 同步远端 / 推到远程 | 将已授权框架改动核验后发布，更新首页记录；不强推覆盖 |
| 列出新增规则 | 查看真实规则变更记录 |
| 回退到 R编号 | 设定状态下核对可恢复范围，备份后回退；不保证任意版本一键完整恢复 |
| 新视频 / 来个新的视频 | 按项目地址入口创建独立视频，确认新作或续写及预设 |
| 续写视频 | 区分物理衔接与逻辑延续，按授权范围继承事实 |
| 列出历史 | 先确认当前项目或其他项目，再列真实历史 |
| 回看某条剧情 / 回看某条提示词 | 只查看指定记录，不自动切换或复用内容 |
| 看剧情 / 看分镜 / 看 H3 提示词 | 回看当前对应内容；未生成分镜时如实说明 |
| 列出预设 / 显示预设 | 查看实际预设，范围不明时澄清 |
| 切换预设名称 | 保存后切换至预设绑定项目，按记录恢复 |
| 恢复预设名称 | 按已确认语义恢复当前视频预设字段，不改无关内容 |
| 保存为预设名称 / 更新预设名称 | 仅保存明确确认的预设字段，保留版本 |
| 列出项目 / 切换到项目或视频 | 查看真实记录；切换前保存，恢复目标独立状态 |
| 技能 / 全局技能 / 当前项目技能 | 查看登记或本项目使用记录；范围不明时询问，不激活 |
| 添加技能 + 地址或文件 | 设定状态下读取并安装固定原包，校验登记；安装不启用 |
| 本次使用某辅助技能 | 明确授权本次调用，再确定全部或部分范围，按融合规则执行 |
| 看技能配置 / 本条用了什么技能 | 查看本条实际技能版本、范围、裁定及融合记录 |
| 生成提示词 | 先完成故事审核、模型与必要确认；H3 每次确认格式，再按规范生成 |
| 落盘 / 保存 | 保存当前授权改动与版本；不自动发布远端 |

list 输出按管理、创作、回看、预设、技能分类展示上述命令及解释，可合并同义词。用户指定类别时只列该类别。不得把完整启动问卷或项目内容混入命令帮助。
