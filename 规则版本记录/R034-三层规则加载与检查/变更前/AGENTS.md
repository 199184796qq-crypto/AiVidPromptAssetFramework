# H3 官方技能冻结规则

架构维护与查找可读根目录 架构导航.md；其分层索引仅指向现有规则，不减少必读范围、不导入参考项目的创作内容或默认设定。

所有 Agent 必须先读取 用户定制规则/硬规则锁定清单.md。清单列出的文件绝对禁止修改、覆盖、删除或自动升级；新增要求只能另存补充规则或新版本。

任何操作只要会离开当前视频编辑状态，必须先执行 用户定制规则/离开编辑状态强制落盘.md，保存并读回核验当前进度后才能继续。列出历史和回看其他记录同样触发此规则。

遵守编辑锁：只有“编辑中/未保存”才执行写盘；“已锁定/已保存”且无新改动时只做可读核验。

每个 H3 提示词必须有对应的剧情版本；读取并遵守 用户定制规则/提示词与剧情双版本规则.md。

跨智能体或跨机器工作必须读取并遵守 用户定制规则/多智能体协同规则.md，使用项目文件和编辑锁协调，不得依赖各自聊天记忆。

同一项目使用 H3、Seedance 2、Seedance 2.5 等多个工具时，必须读取 用户定制规则/多引擎提示词归档规则.md；共同剧情与各引擎提示词分开保存。

项目内每个视频及其可选分镜按 用户定制规则/视频剧情与分镜记录规则.md 执行；只有实际生成分镜才建立分镜记录。

规则恢复、增量列表和回退必须读取 用户定制规则/规则版本与回退控制.md 及当前活动规则索引；回退不删除硬规则或历史文件。

“Agent设定”是框架与规则规划入口，必须读取 用户定制规则/Agent设定入口.md，不得误当作视频生成请求。

只有用户明确开启 Agent 设定后才能新增、修改、启用或回退规则；否则不得写入规则文件。

“列出历史”不得默认范围；保存当前状态后先询问“1. 当前项目；2. 其他项目”，再按选择读取记录。

续写任务先按 用户定制规则/续写类型分流规则.md 分流。物理延续执行冻结衔接基准；逻辑延续采用新开场，不使用重叠帧或物理首镜规则。

启动视频工作必须先读 用户定制规则/项目地址启动入口.md：项目地址为第一问，之后再执行新视频/续写及预设确认。

项目归档遵守 用户定制规则/项目归档与复现.md；归档副本用于恢复，禁止在归档时改写已交付提示词或冻结源文件。

预设与视频项目列表交互遵守 用户定制规则/预设与项目列表.md，支持按数字选择，状态以真实记录为准。

多视频管理必须读取 用户定制规则/多视频切换规则.md；通用规则共享，每个视频的设定、素材、版本与审核状态独立保存和恢复。

h3-prompt-writing/ 是官方原版冻结快照。禁止修改、重写、格式化、覆盖、删除或自动更新其中的任何文件。用户自定义规则及衍生版本必须保存在独立目录，不得写入官方原版目录。

来源版本及校验值见 官方原版来源与校验.json。升级必须获得用户明确指示并另存新版本，保留本快照。

## 用户定制规则入口

在本目录进行 H3 提示词创作时，必须读取并遵守 用户定制规则/参考声线固定句式.md。该规则仅约束任务输出，不得据此修改官方技能。

交付参考声线模式的素材上传顺序时，必须读取并遵守 用户定制规则/参考声音上传提示.md。

用户选择声音驱动时，必须读取 用户定制规则/声音驱动规则.md，并依据官方技能编写；切回参考声线时恢复参考声线规则。

所有声音素材上传条目必须遵守 用户定制规则/声音上传模式标注.md，在每条名称后标明声音驱动或参考声线。

## 完整协议与恢复入口

开始 H3 工作先读取 用户定制规则/H3定制输出协议.md，再读取相关专项规则。继续当前测试时读取 用户定制规则/当前测试状态.md。命名预设机制已启用，读取 用户定制规则/命名预设与本次覆盖.md；不得自动把当前测试设为默认。

跨智能体使用的统一入口为根目录 先读我.md，按其中相对路径读取完整协议及专项规则。

续写视频必须读取 用户定制规则/续写视频首镜衔接规则.md，按 context_latent 衔接逻辑编写首镜，不强制索取上传。

## 续写冻结基准：与官方技能同级保护

续写时必须读取 续写衔接冻结基准-v1/README.md 与 续写衔接冻结基准-v1/已确认续写理解与时间规则.md。
这两份文件及来源校验记录，与官方技能享有相同的不可改写、不可覆盖、不可删除、不可自动更新保护。用户定制规则/续写视频首镜衔接规则.md 也是同内容的只读规则，不得继续追加改写。
这里的同级指用户项目内的保护与执行基准，不能覆盖系统约束，也不把第三方说明称为 MiniMax 官方文件。
后续新增理解或规则只能另存补充或新版本，用户明确确认后才生效，仍保留 v1 原件。遇到两份基准具体冲突先说明，不擅自修改任一原件。



每次完整交付必须读取 用户定制规则/素材顺序设定首行.md：第一块首行写明沿用的预设或本次已确认设定及有效六项，随后排列素材。
