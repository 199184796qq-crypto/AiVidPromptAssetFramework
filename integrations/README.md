# 外部协同边界

VDE 的项目位置仅是可配置来源，不是本框架运行的强制依赖。本次架构参考不等于已授权调用 VDE 创作。

- 视觉协同按 [VDE 协同规则](../用户定制规则/VDE视觉导演引擎协同.md) 读取本项目已确认视觉资料；来源缺失不虚构加载，不把参考项目的风格库、人物案例写入默认预设。
- 辅助技能按 [扩展机制](../用户定制规则/辅助技能扩展机制.md) 与 [每次明文启用](../用户定制规则/辅助技能每次明文启用.md) 执行；原包与融合层分别管理。
- 多 Agent 按 [协同规则](../用户定制规则/多智能体协同规则.md) 交接；项目文件留在项目内，不进入公共框架发布包。

参考项目的优先级、输出顺序或默认参数不自动成为本框架规则。遇到现有协议冲突，保留双方依据，按框架裁定流程处理。
