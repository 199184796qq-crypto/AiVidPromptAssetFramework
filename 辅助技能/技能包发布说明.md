# 技能包发布说明

用户在本次发布中明确要求“要上传技能包哦”，授权将当前五个已安装辅助技能的版本文件上传到 AiVidPromptAssetFramework 仓库。本说明更新此前安装记录中“仅同步登记、不上传包”的本次发布处理方式；原安装记录作为历史保留。

发布范围：asset-driven-cinematic-video-prompt 1.0.0、character-four-view 1.0.0、color-palette-prompt 1.0.0、h3-martial-arts-director 1.2.0、scene-anchor-multiview 1.0.0。

完整文件位于 packages/{id}/{version}/，保留安装版本原文。此用户上传授权不冒称上游开源许可证，也不改变未提供上游许可的事实。

其他 Agent 应核验技能登记表中的入口 SHA256 并读取完整技能及必要引用。登记表的 installed 反映来源机器状态；下载后仍须核验本机文件及依赖。发布不表示已自动启用，使用时按项目选择和框架规则执行。
