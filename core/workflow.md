# 任务路由

相对链接以本文件为基准。此表用于查找，实际执行以所链接规则及根目录先读我为准。

| 任务 | 读取入口 | 执行边界 |
| --- | --- | --- |
| 版本、指令查询 | [版本](../用户定制规则/框架版本查询.md)、[指令](../用户定制规则/框架指令查询.md) | 只读，不启动创作 |
| 框架设置与更新 | [设置](../用户定制规则/Agent设定入口.md)、[更新](../用户定制规则/框架升级与同步.md)、[回退](../用户定制规则/规则版本与回退控制.md) | 设置授权、版本与备份；不改冻结文件 |
| 项目建立与恢复 | [项目地址](../用户定制规则/项目地址启动入口.md)、[项目入口](../用户定制规则/项目先读我与项目级更新.md) | 先确认地址，读取项目入口；初始化按原规则完整读取 |
| 新视频或续写 | [视频切换](../用户定制规则/多视频切换规则.md)、[续写分流](../用户定制规则/续写类型分流规则.md)、[隔离](../用户定制规则/视频内容与写法隔离.md) | 物理衔接与逻辑续写分开，独立视频不继承旧写法 |
| 共同输入 | [预设](../用户定制规则/命名预设与本次覆盖.md)、[资产](../用户定制规则/项目资产管理.md) | 只用确认字段和本次实际输入 |
| 故事到提示词 | [故事审核](../用户定制规则/故事先审后选模型.md)、[模型路由](../integrations/models.md) | 故事通过后选模型，必要确认完成才生成 |
| 辅助技能 | [明文启用](../用户定制规则/辅助技能每次明文启用.md)、[融合](../用户定制规则/辅助技能融合规则.md)、[原包保护](../用户定制规则/辅助技能原包保护与融合层.md) | 每次授权、范围与依赖、冲突裁定 |
| 交付与保存 | [占位符](../用户定制规则/模型资产占位符交付规则.md)、[先交付](../用户定制规则/提示词优先交付.md)、[落盘](../用户定制规则/离开编辑状态强制落盘.md)、[归档](../用户定制规则/项目归档与复现.md) | 两块输出、版本对应；只对脏状态保存 |

不能因为流程表省略某专项条目而跳过根入口的必读要求。项目冲突由用户判断，辅助技能或外部视觉方案不能自动替代主流程。
