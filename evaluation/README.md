# 架构与兼容性检查

运行 `tools/check_framework.ps1` 可只读检查新导航的链接、活动版本日志、重复版本标题及辅助原包清单。脚本不修改任何文件，不自动修复、不联网、不生成提示词。

PASS 表示该检查项成立；WARN 表示历史记录或校验资料需要人工核实；ERROR 表示必需入口缺失或原包校验不一致。脚本不是生成质量评估，也不能证明所有语义冲突均已消除。模型生成仍执行原输出协议及对应冻结校验。

架构维护需保存修改前原件和本次文件清单，核验参考目录、冻结目录、辅助原包及未涉及规则在维护前后未变。目录和文件链接应在复制到其他路径后仍能解析。保留原路径，避免破坏已有项目规则副本和历史绑定。
