# 视频内容与写法隔离

状态：R016，用户在 Agent 设定状态明确要求。适用于所有项目、模型、辅助技能及 Agent 的视频提示词创作与修改。

## 每个视频独立

每个视频以项目标识和视频标识确定独立编辑范围。不论当前提示词修改多少次，修改只进入该视频自己的版本和必要关联剧情，不回写此前视频，不自动传播到以后视频，不自动生成通用规则、示例库或默认写法。
同一项目、同一人物、同一模型、连续处理顺序、曾通过审核，都不能成为继承其他视频提示词的依据。相同视频恢复编辑时只恢复它自身的有效版本；切换后不得把刚编辑视频的内容带入目标视频。

## 新视频的输入边界

新视频仅依据本次用户提供或明确确认的输入、已确认采用的预设字段，以及框架和所选模型主技能规定创作。辅助技能还须满足每次明文启用规则。
禁止主动检索、读取、模仿、归纳学习或复用其他视频提示词来决定新视频的写作风格、措辞、句式、详略、段落节奏、镜头习惯、运镜、动作设计、对白、人物、场景、道具、声音或光线。禁止把其他视频成稿作为隐含范例、模板或质量基准。
其他视频即使仍在聊天上下文中也不得作为创作依据。这是可执行的内容来源约束，不宣称能清除模型上下文或实现技术上的记忆隔离。框架规定的固定格式和主技能本身的规范仍按其来源执行，不能将历史视频写法冒称为技能规范。

## 预设只继承明文确认字段

预设是唯一允许自动带入的已确认创作基线，且须满足每次预设确认规则。仅应用预设中实际保存并确认的字段和值，不从创建该预设的旧视频推断任何额外内容。影视风格字段不等于旧提示词的写作风格；选用同一预设不授权模仿旧文案。
本次覆盖只留在当前视频。修改预设须用户明确要求，保留版本，不追溯更新其他视频。选择预设导致项目切换时，也不能把恢复的旧视频内容当作新视频的创作素材。

## 续写与明确本次输入

新视频与续写按既有入口区分，不因相邻视频自动认定续写。用户明确选择逻辑或物理续写时，只提取本次授权的剧情事实或必要衔接状态，并记录来源和继承范围；不继承上一段提示词的措辞、结构习惯或写作风格。物理续写仍读取冻结衔接规则，冻结原件不改。
用户在本次明确提供的素材或描述可作为本次输入；只允许其明确用途，不由此扩展为可参考整个旧视频。请求复用旧视频写法若与本隔离规则冲突，应指出冲突并交用户决定，不静默放宽。
查看历史仅用于回看，不授权将历史内容用于新创作；切回创作时恢复目标视频的独立输入范围。

## 交付与保存检查

生成前确认当前项目、视频、有效本次输入、已确认预设及合法续写继承范围。资料不足时询问或在用户授权范围内独立设计，不能用旧视频补空。
交付前核对新增角色、内容、光线、声音与写法来源：发现来自其他视频且不属于已确认预设字段或明确续写事实的内容，移除并按本次输入重写。检查不得以搜索其他视频作为必需步骤，以当前允许输入与实际调用记录核对。
在该视频记录本次输入来源、预设名称及版本、续写来源和允许继承项（没有则为空）、当前修改范围及版本。保存和归档按既有编辑锁执行，历史提示词保持不变。其他 Agent 接手按这些记录恢复，不以聊天印象或其他项目成稿补全。
