# 辅助技能每次明文启用

状态：R015，用户在设定状态明确要求。适用于所有辅助技能及其融合层。

默认不使用辅助技能。每次调用前必须有用户针对本次使用的明确文字指令，能确定技能及使用对象，例如：本次使用武术指导优化这段动作。也接受对明确启用问题的文字确认或数字选择；只提技能名但用途不明时澄清，不自行启用。
安装、添加、升级、查看技能、讨论规则、引用技能咨询、预设绑定、历史使用记录、恢复项目和 Agent 推荐均不构成本次启用。不得因题材匹配或认为有帮助自动调用。没有本次明文指令时按主框架与模型主技能工作，不强制用户先选择辅助技能。

## 授权边界

本次授权覆盖明确指定的技能、对象和范围及完成该次调用所需步骤，分轮回答必需问题不要求重复启用。该次调用完成、取消或切换对象后授权结束；再次调用、重新优化或新视频均须新的明确使用指令。只说继续、重新生成或沿用预设，不自动再次调用已完成的辅助技能。
用户明确说本次继续使用同一技能，可以复用既有配置和适用裁定；历史授权本身不能代替本次授权。保留已有产出不等于再次调用，无授权时不删除先前已确认的技能成果，也不虚构新调用。
若必要依赖包含另一独立辅助技能，先列明并取得本次使用授权；选中原技能包内部必需引用按已授权范围读取。融合层随本次明确指定的辅助调用加载，不得通过主动启用融合层绕过原技能授权。

## 记录与执行

记录 activationEvidence（用户实际指令及确认）、activationTarget、activationScope、activationStatus，关联具体调用与输出版本；不捏造授权文本。无调用时 skills 为空，历史记录保留；跨 Agent 恢复不自动产生新调用授权。
此规则只调整框架调用门槛，不修改辅助技能原包或其宿主元数据。原包保护继续按 R014；授权后再执行 R013 的范围确认、依赖检查和融合流程。本规则替代此前允许沿用历史启用或复用授权自动调用的表述，配置与已确认事实仍可复用。
