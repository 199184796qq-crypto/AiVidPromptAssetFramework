# H3 Agent 硬规则锁定清单

状态：永久锁定。任何 Agent、智能体、脚本或自动流程均不得修改、覆盖、删除、重命名、格式化、自动升级或静默替换本清单及其列出的文件。

## 不可修改文件

1. `E:\H3的技能\h3-prompt-writing\` 目录及其全部文件：MiniMax H3 官方技能冻结快照。
2. `E:\H3的技能\续写衔接冻结基准-v1\` 目录及其全部文件：物理续写 Motion Context 冻结基准。
3. `E:\H3的技能\用户定制规则\续写视频首镜衔接规则.md`：物理续写首镜规则冻结副本。
4. 本文件 `硬规则锁定清单.md`。

上述文件享有最高的用户框架保护级别。官方技能和续写冻结基准的来源校验记录也一并保护。

## Agent 执行限制

- Agent 只能读取硬规则，不能以用户未明确的方式改写其中任何文字、字段、顺序、示例、编号或技术参数。
- 任何新理解、新需求或与硬规则相关的修订，只能另存为补充规则或新版本，保留原文件；不得直接编辑硬规则文件。
- 硬规则与普通规则或临时要求冲突时，保留硬规则原文，说明冲突，并在独立补充文件中记录可行适配，不得擅自替换。
- Agent 不得通过复制后覆盖、重命名后替换、批量格式化、自动同步、版本升级或删除再重建来规避锁定。
- 生成提示词前必须确认硬规则文件可读取且校验未变化；读取失败或校验变化时停止涉及该硬规则的生成并报告异常。

## 可修改范围

只有用户明确要求新增或修改普通用户定制规则时，才可编辑 `用户定制规则` 中未列入本清单的文件。即使如此，也不得改变硬规则的含义、优先级或保护状态。

## 发现异常

如果发现硬规则文件被改动、缺失、校验不一致或权限被解除，Agent 必须停止相关任务，保留现有文件，不自行恢复或重写，并向用户报告具体文件和异常类型。
