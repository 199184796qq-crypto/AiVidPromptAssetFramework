# 辅助技能原包保护与融合层

状态：R014，用户明确要求。辅助技能添加后原包不得修改，之后的行为调整统一修改独立融合层。本规则从当前已安装快照开始生效，不追溯改写或恢复历史包。

## 原包不可改

保护范围为框架辅助技能/packages/及辅助技能/历史停用/中已安装的每个固定版本及其所有文件，包括 SKILL.md、references、脚本、资源和元数据。Agent 不得改写、覆盖、删除、重命名、格式化、解除只读后编辑，也不得以升级、同步或修复名义替换同版本。来源宿主技能也不得被当作修改后再回灌原包的绕行位置。
用户说调整某辅助技能时，默认调整融合层；不得沿用以前直接编辑宿主源包的做法。发现原包异常时停止使用该版本，报告校验差异，保留证据，不自行覆盖恢复。规则要求与文件只读属性不能代替操作系统权限隔离，不宣称技术上绝对无法被修改。

## 独立融合技能

融合层统一存放于 辅助技能/融合技能/{fusion-id}/{version}/SKILL.md，并用同目录 fusion.json 记录融合 id、版本、绑定原技能 id/版本/各文件校验、选中范围、必要依赖、流程适配、输出映射、用户裁定、前版及变更说明。只有实际需要适配时才创建具体融合技能，不为所有插件虚构融合内容。
融合层调整角色引导、步骤顺序、组合方式、局部优化或交付适配；明确原始要求与已获用户授权的差异，不冒称修改后的规则是原技能规定。涉及原技能强制要求冲突仍按辅助技能融合规则.md交用户判断。
使用时读取固定原包及其适用引用，再读取绑定的融合层，执行选中范围、必要依赖和有效裁定；不得仅凭融合层忽略原包。主框架和模型主技能职责不变。

## 修改、升级和回退

只有用户开启 Agent 设定并授权通用改动时，才新增融合版本；保留旧版，记录前后关联。项目中的一次性参数修改只记录在本次使用配置，不自动修改公共融合技能。
外部提供真正的新技能版本时，经用户授权可安装到全新版本目录，保留旧原包；不得将 Agent 自行改写原包包装成新版本绕过本规则。新原包与既有融合层重新核验兼容性，未经核验不自动换绑项目。
回退通过选择既有原包和融合版本实现，不覆盖文件。归档同时记录原包版本、校验及融合 id、版本、入口、校验和裁定；未使用融合层明确记为无，不虚构调用。

## 校验与跨 Agent

原包文件清单与 SHA256 独立存入 辅助技能/原包校验清单.json，不能在发现原包变化后静默重算作为合法新基准。新增授权版本可以追加清单，旧条目保留。加载与同步时核对文件缺失、新增及内容变化；校验失败不激活。
发布时同时携带允许发布的原包、校验清单、实际存在的融合版本及使用入口。其他 Agent 按绑定恢复；缺失融合层或不匹配时报告，不临时改原包。Windows 只读属性不随 Git 自动传播，接手端仍须校验并设置当地可用的保护。
