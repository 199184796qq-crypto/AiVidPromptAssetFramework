# 故事先审后选模型

状态：用户确认，R009。适用于全部项目、视频及生成工具。

## 必须顺序

1. 按项目入口确认项目、新视频或续写及必要的通用创作信息。
2. 先生成本段通用文字故事：以自然、丰富、连贯的语言写清环境、情节因果、人物动作、情绪变化、对白和结尾。服从已确认时长及事实，不堆砌超出片段容量的事件；不带模型字段、素材标签或工具语法，也不自动生成分镜。
3. 将故事交给用户审核。未明确通过就继续修改故事，不进入基础提示词生成。记录故事版本及独立审核状态。
4. 故事通过后，让用户选择 MiniMax H3、Seedance 2、Seedance 2.5 或其他目标模型。若此前已明确指定，此时回显该选择，不重复索要。
5. 读取所选模型对应主 Skill 及必需引用，以获准故事版本生成该模型的基础提示词。只调用实际存在且适配的技能；缺失时说明并引导提供，不用其他模型格式冒充。不能因适配而擅改故事、对白或已确认设定，遇到时长或能力冲突先说明。

## 版本与修改

本段通用故事作为视频的剧情版本保存，可在尚无提示词时通过“看剧情”回看。已有当前提示词时，“看剧情”仍显示其对应故事版本，并提示另有待同步的新故事（若存在）。不同模型提示词可引用同一已通过故事版本，记录明确对应关系。
故事通过不等于提示词通过；提示词仍按中文先审和原有交付规则执行。只改故事不自动改已有提示词；要求生成或同步时基于指定故事版本更新对应工具分支。已通过且内容未变的故事可以复用，不重复审核。

## 与现有规则关系

本规则替代“先询问模型再创作故事”的普通流程描述。冻结官方 Skill 保持原样；其格式生成阶段放在故事通过和模型选择之后。模型专属参数及辅助技能整合按需进行，影响已确认故事时返回故事审核。提示词优先交付规则只约束准备完成后的展示和管理顺序，不跳过故事审核。
