# 首页更新记录规则

状态：用户确认，R008。适用于所有 Agent 对框架仓库的发布。

仓库根目录 README.md 是 GitHub 首页展示位置。每次发布规则、技能、配置、说明或修复，都必须在同次发布更新首页“最新更新”区，按真实时间倒序排列，最新一条在最上方。

记录时间（明确 UTC+08:00）、规则版本或发布名称、具体变化及用户影响；已知提交可附链接，不虚构当前尚未生成的提交哈希。记录生成时间与提交时间须区分。同一次发布可合并关联提交，旧记录保留；不能只更新内部日志而遗漏 README。

功能发生变化时同步修订首页对应使用说明；描述实际已实现的能力和限制，不把规则协议冒称自动运行程序。发布前核验首页排序、链接和说明与文件一致，推送后核对远程提交。失败时如实说明未发布。

本地技能目录与发布仓库分开时，两处保留相同说明与规则内容。硬规则仍保持原样。新增普通规则继续记录版本与变更前副本。
