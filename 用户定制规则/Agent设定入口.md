# Agent设定入口

状态：用户已确认。`Agent设定` 是框架级入口，不是视频项目指令。

## 含义

用户说“Agent设定”时，进入 AI 视频创作 Agent 框架与规则的规划、启用、检查、版本管理和协同设计状态。此状态处理规则、流程、目录、锁定、回退、项目管理和多智能体协作，不创建视频，不生成 H3/Seedance 提示词，不改变当前视频剧情。

## 开启闸门

只有用户明确说“开启 Agent 设定”“进入 Agent 设定”或同义明确指令后，Agent 设定状态才算开启。未开启时，任何新增、修改、锁定、启用、停用、恢复基线或回退规则的要求只能记录为待议，不得改写规则文件、活动规则索引或变更日志。

用户明确说“退出 Agent 设定”或转入视频工作后，立即关闭该状态；关闭前保存已确认的规则变更。普通的“继续”“生成视频”“列出历史”不自动开启 Agent 设定。

## 开启闸门

只有用户明确说“开启 Agent 设定”“进入 Agent 设定”或同义明确指令后，Agent 设定状态才算开启。未开启时，任何新增、修改、锁定、启用、停用、恢复基线或回退规则的要求只能记录为待议，不得改写规则文件、活动规则索引或变更日志。

用户明确说“退出 Agent 设定”或转入视频工作后，立即关闭该状态；关闭前保存已确认的规则变更。普通的“继续”“生成视频”“列出历史”不自动开启 Agent 设定。

## 执行

进入 Agent 设定后，先读取 `先读我.md`、硬规则锁定清单、规则版本与回退控制和当前活动规则索引，再确认用户要新增、修改、查看、锁定、列出或回退哪一类框架规则。

规则规划完成并经用户确认后，才写入用户定制规则；硬规则仍不能修改。每次离开 Agent 设定状态前，按编辑锁和强制落盘规则保存规则变更、版本日志和当前活动指针。

## 与视频指令区分

“开始视频”“新视频”“续写视频”“生成提示词”等才进入具体项目和视频流程。Agent 设定状态下如果用户同时提出视频要求，先保存规则规划状态，再另行启动视频入口，不把规则讨论内容写入视频剧情或提示词。
