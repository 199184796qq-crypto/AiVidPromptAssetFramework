# 模型资产占位符交付规则

状态：R027。适用于所有模型提示词交付，不修改H3或Wan3冻结原件。

提示词生成前的故事、剧情和分镜只使用文案中的人物与场景名称，不提前确定资产名称、提供者、路径或模型占位符。进入提示词阶段后，先给素材上传块，再给提示词文字块。

SD与Wan3的占位符使用`@图1`、`@图2`等；H3使用`<Picture 1>`、`<Picture 2>`等。声音按对应模型格式编号。编号按本次真实上传顺序连续分配，同一素材复用同一编号。

素材块格式：`角色：名称---->占位符`、`场景：名称---->占位符`、`道具：名称---->占位符`、`声音：名称（模式）---->占位符`。用户明确给出磁盘路径时可追加在占位符后；未提供路径不得编造。占位符不证明资产已存在或已上传。

项目规则与全局规则冲突时，按R026暂停并交用户明文选择。
