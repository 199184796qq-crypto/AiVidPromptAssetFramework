# 辅助技能融合规则

状态：用户确认落盘，R013。适用于全部辅助技能、模型、项目和 Agent；补充并修订 R010 的执行范围。技能原始版本不改写。

## 使用范围先确定

每次辅助调用可以完整使用技能，也可以只使用角色指导、动作、运镜等具体部分；这些仅为例子，不是固定模块。先读取所选版本 SKILL.md，识别实际章节、适用条件和必需依赖，不凭技能名称虚构能力。
用户已明确范围时直接沿用；未明确时依据当前任务提出范围供用户确认。先按 辅助技能每次明文启用.md 取得本次明确使用指令；该次调用内部已确认的范围无需重复询问，历史授权不得自动沿用。记录 full 或 partial、选中章节及本次目标。

## 选中范围的流程必须执行

执行前列出选中部分、用途、输入、规定步骤、确认点、输出及必要依赖，标明来源章节。选中部分及其必要依赖必须按规定顺序执行，不能随意抽掉前置条件；未选且无依赖关系的部分无需执行，记录排除原因，不称为已执行。
用户已有输入直接核对复用；需要用户参与时一次只问一项。不能以只用一部分为由绕过适用于该部分的强制要求。若技能明文要求不可拆分、整套运行或依赖未选模块，说明具体影响交用户裁定，不自行认定可拆分，也不静默扩大范围。

## 主框架与主技能职责

框架继续负责项目状态、故事审核、模型选择、素材绑定、输出交付和归档；目标模型主技能负责正式提示词格式。辅助技能提供选中范围内的专业内容，不整体接管主工作流。与辅助技能自身规定存在具体冲突时按下节处理，不能只以主技能负责格式为由隐藏冲突。

## 融合当前版本

以当前编辑的有效版本为底稿，保存修改前版本及关联，明确输入来自故事、分镜、提示词还是资产设定。只补充或修改授权范围，将辅助结果融入已有内容，不以技能模板替换整稿，不改动无关角色、剧情、对白、全局设定或素材引用。
多技能按已确认顺序执行，每一步接收上一步有效结果。内容重复应合并；要求冲突不能采用后调用者自动覆盖。所选范围需要更大改动时先说明影响并取得用户决定。
影响已确认故事或对白时按故事审核规则重新确认；修改提示词同步其对应剧情。只修改剧情而未要求修改提示词时，不自动改提示词。分镜仅在实际存在时记录影响。

## 冲突与完成判断

列明冲突双方、文件章节、具体影响和可行处理方式，由用户裁定；相同范围内已有明确裁定直接沿用。未裁定前停止依赖该裁定的步骤，可继续独立部分。冻结基准不修改。
完成以选中范围和必要依赖为准：逐项执行、适用确认完成、冲突已解决、结果已融合才可标记完成。未完成或未采用部分写明原因；部分调用完成不能表述为完整执行整个技能。

## 归档与跨 Agent 恢复

使用辅助技能/提示词技能记录模板.json，记录技能 id、固定版本、校验值、full/partial、选中章节、排除部分及原因、目标、必要依赖、执行顺序、步骤状态、用户确认和冲突裁定、修改前后版本、融合变化及剧情/分镜影响。
先按提示词优先交付规则交付，再保存关联记录；离开编辑状态按编辑锁落盘。其他 Agent 按记录恢复实际范围和版本，不自动改为全量调用或最新版。既有历史记录缺少范围字段时标为未知，不能推断为全量已执行。

辅助技能原包保护按 用户定制规则/辅助技能原包保护与融合层.md（R014，相对框架根目录）执行：已安装原包不可修改；后续通用行为调整只新增独立融合技能版本，绑定固定原包并记录用户裁定。不得修改宿主源技能后回灌绕过保护。
